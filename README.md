# Skybox Forge

Drop in a picture to get a seamless 2:1 panorama or the six square faces of a Roblox skybox. Everything runs in the browser; no image is uploaded anywhere.

## Put it on GitHub Pages

1. Create a new public repository on GitHub.
2. Upload `index.html` and `.nojekyll` to the root of the repository.
3. Open Settings, then Pages. Under "Build and deployment", set Source to "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://YOUR-NAME.github.io/REPOSITORY-NAME/`.
